Renyi games

Four small games written in Renyi, compiled and run in your browser by the Renyi toolchain built for WebAssembly. Nothing leaves the page. The sources are at github.com/renyi-lang/renyi-games.

The games need a browser with a canvas and WebAssembly.

The arrows or W A S D move and turn; Space or F fires, which starts a game from its title screen; Escape or Q quits. Each game's README says what the keys do in it.
